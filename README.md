# Arknight Agent 基于强化学习的明日方舟Bot
## 设备
- MUMU模拟器
## 注意
由于本人的设备有限，因此该项目是放置在算力服务器上运行，通过接口进行数据传递，client文件为服务器端，main文件为客户端，服务器端负责接受数据并进行动作预测，客户端接受服务器端的数据后进行动作反应
## 环境
- python >= 3.10
## 使用
1，配置好环境后服务器端运行client文件，本人使用的服务器厂商只能通过6006端口进行数据传输，**可以根据实际情况进行修改**

2. 客户端同步运行main文件，接收数据，此时就可以看到agent进行动作反应了
